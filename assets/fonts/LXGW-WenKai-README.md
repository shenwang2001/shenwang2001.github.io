# LXGW WenKai webfont assets

The two WOFF2 files are unmodified font subsets from
[`lxgw-wenkai-webfont` 1.7.0](https://www.npmjs.com/package/lxgw-wenkai-webfont):

- `lxgwwenkai-bold-subset-115.woff2` contains U+7533 (`申`).
- `lxgwwenkai-bold-subset-116.woff2` contains U+738B (`王`).
