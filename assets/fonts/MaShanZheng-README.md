# Ma Shan Zheng webfont asset

`ma-shan-zheng-regular-wang-shen.woff2` is a WOFF2 subset of
[Ma Shan Zheng](https://github.com/googlefonts/mashanzheng) containing only
U+738B (`王`) and U+7533 (`申`). It was generated from the project's regular
TrueType font without altering either glyph.
